# Contributing to ChromaVault

Thank you for considering a contribution.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Include your browser, operating system, Node.js/npm versions, and exact steps to reproduce.
- Include sanitized logs when useful. Never upload passwords, private files, or sensitive pouch contents.

## Pull requests

1. Open an issue first for large changes so the scope can be discussed.
2. Keep pull requests focused and explain the reason for each change.
3. Avoid unrelated formatting or refactoring.
4. Add or update tests for behavior changes where practical.
5. Run `npm run lint`, `npm run test`, and `npm run build` when possible, and report which commands passed.
6. Describe any limitations or known regressions clearly.
